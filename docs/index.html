台湾

■政治経済：中国系ハッカーがAIを使い台湾に初の「自律型」サイバー攻撃を実施
中国と関連するハッカー集団が、AIエージェントを活用した史上初の自律型サイバー攻撃を台湾に対して行ったと報告された。オープンソースのHermesおよびOpenClawエージェントが使用されており、人間の介入なしに攻撃が遂行された点が新たな脅威として注目されている。

■その他：太平洋で中国調査船の「芝刈り機」パターンの航行が疑惑を呼ぶ
中国の海洋調査船が太平洋において、格子状に往復する「芝刈り機」パターンの航行を繰り返していることが確認され、海底地形や軍事目的のデータ収集ではないかとの疑念が高まっている。台湾周辺の安全保障環境への影響も懸念されている。

中国本土

■政治経済：中国の自動車輸出、2カ月連続で100万台突破
中国の自動車輸出台数が2カ月連続で月間100万台を超えたことが明らかになった。電気自動車（EV）を中心とした輸出攻勢が続いており、中国が世界最大の自動車輸出国としての地位をさらに強固にしつつある。日本や欧米の自動車メーカーへの競争圧力がいっそう高まることが予想される。

■エンタメ：Honorがロボット搭載スマートフォンを正式発表
中国のスマートフォンメーカー「Honor（栄耀）」が、数カ月にわたりその存在が噂されていたロボット機能搭載スマートフォンを正式に発表した。AIと物理的なロボット機構を組み合わせた革新的な製品として注目を集めており、スマートフォン市場に新たなカテゴリーを切り開く可能性がある。

■その他：中国、長征7A型ロケットの打ち上げに失敗―衛星も喪失
中国の長征7Aロケットが打ち上げから85秒後に空中分解し、搭載していた通信衛星「中星4B」とともに失われた。中国の宇宙開発において近年まれな大きな失敗事例となり、商業衛星打ち上げサービスの信頼性や今後のスケジュールへの影響が懸念される。

アメリカ

■エンタメ：NBAの名手ラッセル・ウェストブルック、18シーズンの現役生活に幕

■その他：ホプキンスの保育施設で2人の大人と1人の子供が死亡、無理心中か
ミネソタ州ホプキンスの保育施設で大人2人と子供1人が死亡する事件が発生し、警察は無理心中（殺人・自殺）の疑いで捜査を進めている。子供が預けられる保育施設での惨事に地域社会に大きな衝撃が走っている。

イギリス

■エンタメ：アッシャー＝スミスとハントが200mファイナルへ、英国勢3人組が躍進

■その他：日食観測にザルを使う男性がロンドンの公園に出現、話題に
ロンドンの混雑した公園で、男性がザル（コランダー）を使って日食を観測する様子が目撃され、注目を集めた。彼だけでなく同様の手法を試みた人々も確認され、日食フィーバーの中で生まれたユニークな光景としてSNS等で話題となっている。
