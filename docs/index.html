台湾

■その他：ムバッペがルブロンやセナらとともに中国に膝を屈する
サッカースター、キリアン・ムバッペがレブロン・ジェームズやジョン・シナといった著名スポーツ選手・エンターテイナーに続き、中国市場への配慮とも取れる行動をとったと報じられた。国際的なスポーツ・芸能界における中国の影響力の大きさが改めて浮き彫りとなっている。

中国本土

■政治経済：中国、EUの輸入規制計画に対抗姿勢を鮮明に
北京はブリュッセルが進める中国製品の輸入制限措置に対し、強硬な姿勢で対抗する構えを見せている。米中貿易摩擦が続く中、中欧間の通商関係にも緊張が高まっており、今後の交渉の行方が注目される。

■その他：中国の家庭、子どもより高齢者の扶養負担が増大
中国では少子高齢化が急速に進み、各家庭が扶養する高齢者の数が子どもの数を上回る状況になっている。一人っ子政策の影響と出生率の低下が重なり、社会保障制度への圧力が今後さらに増すと懸念されている。

アメリカ

■その他：イスラエル選挙、出口調査では過半数獲得の政党なし
イスラエルで行われた選挙の出口調査によると、いずれの政党も明確な勝利を収められていないことが示された。連立政権の形成交渉が複雑化する可能性があり、中東情勢への影響も含めて今後の動向が注目される。

■その他：戦火の国、飢饉の瀬戸際に
